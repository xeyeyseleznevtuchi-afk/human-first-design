# Human-First Design v1.1.0

Практический, самостоятельный agent skill для работы с Figma, React/shadcn,
Tailwind, Tilda и UX AI-систем. В основе: осмысленная арт-дирекция,
дисциплина дизайн-систем, честный visual QA и 39 принципов из статьи
Taras Bakusevych [39 Principles for Designing Human–AI Interaction](https://syntaxstream.substack.com/p/42-principles-for-designing-humanai).

## Что добавлено в v1.1

- Taste Skill **v2.x**, а не старые три «ручки» — направленный creative brief,
  доказуемые предметные референсы, отдельный путь для B2B/dashboard,
  цикл browser screenshot → 3 issues → fixes → re-test.
- Быстрая маршрутизация `create / redesign / audit / ai-flow / handoff`.
- `references/decision-playbook.md`: какой AI-паттерн выбирать и где approval.
- `references/ai-test-cases.md`: 19 проверочных UX-кейсов для AI/агентов/UI.
- Три дополнительных шаблона: визуальное направление, состояния, QA.
- Проверяемые скрипты: структурная проверка пакета и осторожный статический
  HTML preflight; оба без сетевых запросов и сторонних библиотек.

## Установка в Claude Code

1. Распакуйте архив: в нём должна быть папка `human-first-design`, внутри — `SKILL.md`.
2. Поместите её в `~/.claude/skills/human-first-design/` для пользовательского скилла
   или в `.claude/skills/human-first-design/` внутри нужного проекта.
3. Вызовите `/human-first-design` или напишите задачу: например, «проверь
   существующий UI на системность, адаптив, AI-slop и неподтверждённые действия».

Для других агентов с поддержкой `SKILL.md` используйте их установленный путь
для скиллов. Это **не** plugin и не автоматическое изменение существующих
настроек Claude Code, Codex или ChatGPT.

## Тестирование пакета

```bash
python3 scripts/validate_skill.py
python3 -m unittest discover -s tests -v
python3 scripts/static_check.py path/to/page.html --json
```

Последний скрипт — **эвристика по разметке**, не browser/visual/security audit.
Для настоящей визуальной проверки откройте сайт/макет и пройдите сценарии.

## Примеры постановок задач

- «Сделай страницу магазина, сохрани бренд и подтверждённые тексты;
  придумай предметную композицию, не добавляй шаблонные блоки».
- «Проверь 3 ключевых состояния AI-поиска: источник результата, согласование
  действия и сбой; только audit, ничего не меняй».
- «Приведи новую секцию в соответствие с нашей Figma темой без detached
  instances; потом проверь 390/820/1440 и RU длинные названия».
- «Сделай AI-помощника для таблицы заявок: ни один отправленный запрос не
  должен выполняться без подтверждения, права серверные».

## Структура

- `SKILL.md` — маршрутизатор и правила приоритетов.
- `references/` — углублённые инструкции: дизайн, AI, безопасность, UX QA,
  визуальные источники и связь с оригинальными 39 принципами.
- `examples/` — образцы B2B AI поиска и локального сайта.
- `templates/` — brief, audit, handoff, visual-direction, state-matrix, QA.
- `scripts/`, `tests/` — независимая проверка структуры и HTML preflight.

## Границы и источники

Skill **не является** официальной версией Claude Frontend Design, Taste Skill
или материала Syntax Stream. Здесь свои формулировки и UX-интерпретации; не
переносится сторонний код/иллюстрации. Источники и точные ограничения:
`references/sources.md`. В опубликованном тексте статьи 39 принципов, хотя
историческая ссылка содержит `42`.

Оригинальные локальные файлы навыков пользователя не были доступны; интеграция
с имеющимся у него `audit-design-system` — на уровне совместимых требований,
а не автоматической установки этого дополнительного скилла.
